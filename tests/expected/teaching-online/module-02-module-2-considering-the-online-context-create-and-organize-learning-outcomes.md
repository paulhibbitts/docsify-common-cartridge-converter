# Module 2 - Considering the online context, create and organize learning outcomes.

**The course outcome is to:**

Consider the online learning environment and ***create and organize course outcomes / learning objectives***

The purpose of this module is to get you to consider the online environment and what you need to think about as you start planning your online courses. We will be designing our courses with the end in mind. This process starts with you deciding what it is you want students to be able to do or demonstrate by the end of your course. Once we have this we will then work backwards to create course outcomes and module learning objectives which will be aligned with assessments and learning materials.

> [!TIP]
> **Learning Objectives**
> 1. Use the "[Understanding by Design](https://cft.vanderbilt.edu/guides-sub-pages/understanding-by-design/) " framework and considerations to teaching online, to start planning your online course with the end in mind.
> 2. Create course outcomes for your online course using the formula  **Action**  **Verb +Noun+ Context = Outcome** , which clearly articulate what students will be able to do by the end of your course.
> 3. Breakdown each course outcome into learning objectives using the formula **Action**  **Verb +Noun+ Context = Learning Objective** , which clearly articulate what the student will be able to do at the end of the module.
