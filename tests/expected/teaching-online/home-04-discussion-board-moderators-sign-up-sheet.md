# Discussion board moderators sign up sheet

- Each week, two members of the group will be monitoring the discussion boards. Each of you will moderate twice. Moderators will be responsible for reading all posts, connecting people’s ideas, asking good questions and prompting for more detail if appropriate.
- Discussion board entries will need to be completed by the **Wednesday** of each week, so that moderators have a chance to reply to posts by the **Friday** of each week.
- There are 4 groups of 5 students.
- You canchoose which group you want to be in andsign up to be moderator 1 **AND** moderator 2, on dates that are suitable for you.
