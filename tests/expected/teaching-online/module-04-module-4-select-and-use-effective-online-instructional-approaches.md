# Module 4 - Select and use effective online instructional approaches.

**The course outcome is to:**

*Select and use effective online instructional approaches and align with outcomes.*

The purpose of this module is to continue using the Understanding by Design framework to plan learning experiences and instruction that are aligned with the module learning objectives.

> [!TIP]
> **Learning Objectives**
> 1. Select appropriate content and learning activities to ensure students learn what you want them to learn.
> 2. Align the learning experiences and instruction with the module learning objectives.
