# Module 2 - Beyond Basic 2D Animation

At this point you should have a basic understanding of how to draw objects and backgrounds in Animate and how to create simple animations using Motion Tweens.

In this module we'll be digging a bit deeper into the story-telling aspect of animation and creating short films around subjects of your own choice. Concepts explored in this section include: the use of sound; the use of Scenes; frame by frame animation to create realistic movement like walk cycles; and the development of backgrounds. We'll essentially be looking at how to make your animations more complex and realistic by adding more features.
